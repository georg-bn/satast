A small image matching benchmark between satellite and astronaut images, using hand annotated correspondences on images
from [AIMS](https://openaccess.thecvf.com/content/CVPR2023W/IMW/html/Stoken_Find_My_Astronaut_Photo_Automated_Localization_and_Georectification_of_Astronaut_CVPRW_2023_paper.html)/[EarthMatch](https://github.com/gmberton/EarthMatch).

The benchmark is released as part of the RoMa v2 paper. For an example evaluation script, see the RoMa v2 repo [here](https://github.com/Parskatt/RoMaV2/blob/main/src/romav2/benchmarks/satast.py).
